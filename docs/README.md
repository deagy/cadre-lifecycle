# Cadre-Lifecycle Documentation

This directory contains documentation for the cadre-lifecycle repository.

## Contents

- `examples/` - End-to-end workflow examples

## Overview

cadre-lifecycle is a Cline plugin that provides lifecycle management for agentic
software development. It integrates with the Cadre framework and Agentic SDLC
to provide structured development workflows.

## Key Components

- **cline/** - Main Cline plugin
- **cline-agents/** - Agent team management plugin
- **cline-lifecycle/** - Lifecycle management plugin

## Related Repositories

- [cadre](https://github.com/deagy/cadre) - Core framework and CLI
- [agentic-sdlc](https://github.com/deagy/agentic-sdlc) - Software Development Lifecycle governance
